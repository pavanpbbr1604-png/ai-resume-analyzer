# Library Decision Table & Technical Research

## Mandatory Library Research & Selection Matrix

| Technical Requirement | Candidate Library | Selected | License | Official Docs | GitHub Repo | Primary Purpose | Key Advantages | Limitations | Alternatives Considered |
| :--- | :--- | :---: | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **DOCX Parsing & Modification** | `python-docx` | **YES** | MIT | [python-docx Docs](https://python-docx.readthedocs.io/) | [python-docx GitHub](https://github.com/python-openxml/python-docx) | Inspecting and modifying DOCX paragraphs, runs, formatting, and XML structures | Mature, standard Python library for DOCX OOXML manipulation; full support for font, size, bold, italic, underline, color, paragraph alignment, and spacing | Does not natively compute visual pixel bounding boxes or render page layouts | `docxtpl`, low-level `lxml` parsing |
| **PDF Extraction & Annotation** | `PyMuPDF` (`fitz`) | **YES** | AGPL-3.0 / Commercial | [PyMuPDF Docs](https://pymupdf.readthedocs.io/) | [PyMuPDF GitHub](https://github.com/pymupdf/PyMuPDF) | High-performance PDF loading, text bounding box extraction, rendering page images, highlight annotations | Extremely fast, accurate coordinate-based text extraction, canvas rendering for PDF preview overlays | AGPL-3.0 copyleft license for commercial distribution | `pdfplumber`, `pypdf`, `fitz` |

| **Browser Document Editor** | `ONLYOFFICE Docs API` | **YES** | AGPL-3.0 / Commercial | [ONLYOFFICE Api Docs](https://api.onlyoffice.com/) | [ONLYOFFICE GitHub](https://github.com/ONLYOFFICE) | Browser-based WYSIWYG DOCX viewer/editor, plugin API, Office API interaction | Standard enterprise web document editor; supports real-time editing, formatting, cursors, native document saving | Requires ONLYOFFICE Document Server running via Docker/Server | Custom Canvas/SVG word processor (Rejected: violates no-reinvent principle) |
| **Fast Fuzzy String Matching** | `RapidFuzz` | **YES** | MIT | [RapidFuzz Docs](https://rapidfuzz.github.io/RapidFuzz/) | [RapidFuzz GitHub](https://github.com/rapidfuzz/RapidFuzz) | Keyword normalization, typo tolerance, section heading matching | C++ optimized Levenshtein/Jaro-Winkler distance, 10-100x faster than fuzzywuzzy | String-level only, no semantic understanding | `fuzzywuzzy`, `jellyfish` |
| **Semantic Similarity Embeddings** | `sentence-transformers` | **YES** | Apache-2.0 | [SBERT Docs](https://www.sbert.net/) | [SBERT GitHub](https://github.com/UKPLab/sentence-transformers) | Sentence & bullet point semantic similarity matching against Job Description requirements | State-of-the-art transformer embeddings (`all-MiniLM-L6-v2`); maps bullet points to JD requirements semantically | Requires model download (~80MB) and CPU/GPU memory | `spacy` vectors, OpenAI embeddings API |
| **NLP Pipeline & Entity Extraction** | `spaCy` | **YES** | MIT | [spaCy Docs](https://spacy.io/) | [spaCy GitHub](https://github.com/explosion/spaCy) | Tokenization, POS tagging, noun phrase extraction, section boundary detection | Industry standard NLP framework; fast, robust tokenization and rule-based entity matching | Requires downloading language models (`en_core_web_sm`) | `NLTK`, `Stanza` |
| **Backend REST API Framework** | `FastAPI` | **YES** | MIT | [FastAPI Docs](https://fastapi.tiangolo.com/) | [FastAPI GitHub](https://github.com/fastapi/fastapi) | Async REST API server, request validation, background processing | Native async support, automatic OpenAPI docs, seamless Pydantic v2 integration | Requires ASGI server (`uvicorn`) | `Flask`, `Django` |
| **Data Validation & AI JSON Contracts** | `Pydantic v2` | **YES** | MIT | [Pydantic Docs](https://docs.pydantic.dev/) | [Pydantic GitHub](https://github.com/pydantic/pydantic) | Strict validation of LLM structured JSON output, document schemas, API request models | Rust-powered core validation; guarantees AI responses conform to exact JSON schemas | Strict type coercion rules | `marshmallow`, `cerberus` |
| **Database ORM** | `SQLAlchemy 2.0` | **YES** | MIT | [SQLAlchemy Docs](https://www.sqlalchemy.org/) | [SQLAlchemy GitHub](https://github.com/sqlalchemy/sqlalchemy) | Relational database models, version tracking, suggestion persistence | Fully asynchronous ORM support, type-safe queries, migration friendly | Learning curve for modern 2.0 async API | `peewee`, `tortoise-orm` |
